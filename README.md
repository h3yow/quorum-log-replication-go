# Quorum Log Replication（Go，零依赖）

在本机用多节点模拟一套具备多数派提交、领导者协调、动态成员变更、
日志压缩与崩溃恢复能力的复制日志服务。全部数据在本地文件、通信在进程内，
**完全离线、无外部服务、无真实凭据**。

- 选举与故障切换：随机化选举超时 + 领导租约；多数派不可达不提交，
  同一任期不会有两个可服务的领导者。
- 日志复制：多数派确认才可见；`(ClientID, Seq)` 幂等，重试 / 乱序 /
  重复到达不会重复生效或回退状态。
- 持久化恢复：fsync 落盘；崩溃重启不丢已确认结果；文件**截断**与
  **损坏（CRC/魔数）**返回可区分错误，拒绝以不确定状态启动。
- 动态成员变更：联合共识两阶段 + 新节点"先非投票追赶、再获投票权"；
  配置未提交前不算数，变更期间数据不丢不错位。
- 压缩与追赶：快照原子安装，落后节点经 InstallSnapshot + 增量复制追平，
  无空洞、不回滚。
- 并发与读一致：单事件循环无锁状态机；ReadIndex 线性一致读；
  只读观测入口不影响集群行为。

## 快速开始

```bash
go test ./... -count=1          # 单元测试 + 异常链路
go run ./cmd/demo               # 端到端验证（临时目录）
```

详细的一致性语义、故障模型、成员变更规则与验证方法见
[`docs/DESIGN.md`](docs/DESIGN.md)。

## 代码结构

```
internal/raft/      共识核心（选举/复制/提交/租约/成员变更/快照/持久化）
internal/simnet/    可注入分区、丢包、延迟、节点宕机的进程内网络
internal/kv/        被复制的键值状态机（幂等去重、JSON 快照）
internal/cluster/   本地多节点编排（崩溃/重启/分区/扩缩容/观测）
cmd/demo/           统一本地验证入口
```
